# 222Emails Ultra Visual Generation Prompt

## Non-negotiable output contract

**ONE CONCEPT = ONE CANVAS = ONE FINAL IMAGE.**

Create exactly one standalone finished social-media asset for the current concept. The whole canvas must serve one dominant idea.

Never create:
- a collage
- a contact sheet
- a grid of concepts
- a moodboard
- a montage
- a diptych or triptych
- a split-screen showing separate finished concepts
- a thumbnail board
- a multi-post preview
- a page containing several separate social posts
- a mock-up of several finished assets

If a task requests a batch, the batch is a sequence of **separate image files**. Generate one image for concept 1, then a different image file for concept 2, and continue. Never compress or summarise the batch into one canvas.

## Visual standard

The asset must feel like a premium editorial campaign, not an AI concept board. Use one clear focal point, strong negative space, disciplined hierarchy, mobile-feed legibility and a deliberate visual metaphor or framework that makes the idea easier to understand.

Prefer semantic imagery that directly explains the commercial idea. Avoid decorative complexity that does not increase understanding. Do not repeat the same cinematic desk/monitor composition across the campaign. Vary the visual grammar deliberately across photography, editorial still life, simple spatial metaphor, annotated object, clean framework, chart-like composition, typographic poster and carefully controlled interface-inspired visual where appropriate.

## Truth and proof discipline

Never invent:
- recovered revenue
- lead counts presented as actual client data
- conversion rates
- engagement counts
- testimonials
- before/after performance
- pipeline values
- client names or logos
- dashboard data

Do not create fake proof screenshots or fake CRM dashboards. If an example calculation is genuinely useful, label it clearly as an illustrative example and keep it mathematically defensible. Prefer no numbers over weakly sourced numbers.

## 222Emails commercial positioning

The business is positioned around **Revenue Recovery** and **Client Return Systems for appointment-led SMEs**. Visuals should make missed commercial opportunities visible: missed enquiries, weak follow-up, cancellations, no-shows, overdue rebooking, dormant clients, journey friction, poor timing, missing ownership, incorrect classification and weak exit logic.

Do not reduce the category to generic email marketing. Email is a tool. The commercial problem is missed revenue in the client journey.

## Copy discipline

Use UK English. No em dashes. Keep text concise enough to read without zooming. The first two seconds should communicate the premise. One asset should have one primary headline, one primary idea and one clear payoff. Do not fill the canvas with report copy.

Do not depend on image generation for fragile microtext, long tables, exact logos, QR codes or proof-critical figures. Where exact copy or identity matters, leave clean compositional space so deterministic typesetting/source-locked branding can be added later.

## Brand discipline

Use one 222Emails brand mark only when branding is present. Never duplicate logos around the canvas. Never invent or redraw a logo if an exact approved source exists. Avoid malformed wordmarks. Preserve a premium, restrained visual identity with confident typography, strong spacing and an accent used intentionally rather than everywhere.

## Apex campaign mix

For the Apex visual bank, preserve variety across the campaign rather than repeating one aesthetic:
- editorial metaphor photography
- frameworks and maps
- bold typography
- annotated objects or spaces
- simple diagrams
- illustrative calculations only where truth-safe
- human behaviour / customer-state visuals
- restrained humour where appropriate

Every asset should still feel like part of the same 222Emails system through hierarchy, spacing, typography discipline, tone and brand treatment.

## Automatic QA failure

Reject and regenerate the current concept immediately if any of the following occurs:
1. More than one finished concept appears in one image.
2. The result is a grid/contact sheet/collage/montage.
3. The image tries to preview the whole batch.
4. Proof-like numbers are invented or unlabelled.
5. Critical copy is illegible at feed size.
6. A logo is malformed, duplicated or substituted.
7. The image is visually impressive but does not make the commercial point easier to understand.
8. It looks materially too similar to another recent Apex asset without a strategic reason.
9. The generated visual creates a factual claim that cannot be defended.

A failed asset is not a deliverable, not a style reference and not publication-ready. Regenerate it as a standalone asset before moving on.

## Release rule

Visual QA does not equal publication permission. The existing Content OS approval, revision lock, media/source lock, Buffer capacity, cadence, deduplication, fixed-time scheduling and post-publication verification rules remain mandatory.
