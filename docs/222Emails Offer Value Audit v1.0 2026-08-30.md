# 222Emails Offer Value Audit v1.0

Status: INTERNAL COMMERCIAL QA
Date: 2026-08-30

## Method
This is a directional internal score, not market proof. Each offer is reviewed against the $100M Offers-style value levers already compatible with current 222Emails doctrine:
- desired commercial outcome;
- credible likelihood of achieving useful value;
- time to useful value;
- buyer effort/sacrifice.

Scores prioritise improvement. Market conversion and client outcomes outrank the internal score.

## Free Revenue Recovery Check - £0
### Current job
Reveal and diagnose a meaningful missed-enquiry, follow-up, no-show, rebooking or win-back gap and route the prospect to the sensible next step.

### Directional score
- Desired outcome: 8.5/10
- Credible likelihood: 6.5/10
- Speed to useful value: 8/10
- Low buyer effort: 9/10
- Overall directional value strength: 8.0/10

### Biggest value leaks
1. A free diagnostic can feel generic unless the output is visibly specific to the business.
2. Likelihood is constrained by limited appointment-led case proof.
3. The buyer needs to understand what they will receive without interpreting the RRC as a vague free consultation.

### Upgrade
- Give at least one tangible, business-specific diagnostic insight where evidence permits.
- Separate Observed, Likely and Unknown claims.
- Explain the mechanism causing the gap, not only the symptom.
- Give one prioritised next action even when the prospect does not buy.
- Route clearly to no-fit guidance, £197 Growth Check or implementation.
- Keep form-first, asynchronous and low effort.

### Stronger buyer-facing frame
**Find the first place good enquiries or clients are falling out of your return journey, understand what is causing it, and see the most sensible next fix.**

## Client Return Growth Check - £197
### Current job
Quantify the opportunity and turn the diagnosis into an implementation plan.

### Directional score
- Desired outcome: 8.2/10
- Credible likelihood: 7/10
- Speed to useful value: 7.5/10
- Low buyer effort: 8/10
- Overall directional value strength: 7.7/10

### Biggest value leaks
1. The distinction from the free RRC must be extremely obvious.
2. It risks feeling like paying for a report if the output does not materially reduce implementation uncertainty.
3. A buyer may fear paying twice before implementation.

### Upgrade
- Free RRC identifies the likely highest-priority gap.
- Growth Check quantifies, maps the journey, defines logic, priorities, implementation route and measurement requirements.
- Output should be implementation-ready enough that the buyer understands exactly what the build is solving.
- Design a rollover-credit experiment separately, but do not put it live without explicit pricing/commercial approval.

### Stronger buyer-facing frame
**Turn the suspected return gap into a quantified, prioritised build plan with the customer journey, follow-up logic and measurement requirements mapped before implementation begins.**

## 7-Day Client Return System Sprint - £997
### Current job
Install the core Client Return System quickly and end to end within agreed scope.

### Directional score
- Desired outcome: 9/10
- Credible likelihood: 7.2/10
- Speed to useful value: 9/10
- Low buyer effort: 8.5/10
- Overall directional value strength: 8.4/10

### Biggest value leaks
1. Appointment-led proof depth is still developing.
2. '7-Day' is valuable only when access, data and approvals make it operationally achievable.
3. Turnkey scope must stay concrete so the buyer does not read it as unlimited work.

### Upgrade
- Keep the seven-day implementation positioning only with clear start conditions.
- Make the buyer-effort reduction explicit: strategy, copy, design, automation, QA and launch handled end to end where scoped.
- Make excluded major migrations, bespoke integrations, data repair, platform fees and unlimited revisions visible before sale.
- Use launch QA and measurement setup as confidence builders, not decorative bonuses.
- Capture first appointment-led wins with disproportionate founder attention so credible likelihood rises through proof rather than claims.

### Stronger buyer-facing frame
**We identify the highest-priority return gap and install the agreed Client Return System end to end so your team is not left with another strategy document or another tool to learn.**

## Client Return Accelerator - £1,297
### Current job
Premium mixed-channel implementation where the buyer needs a broader return system than the core Sprint.

### Directional score
- Desired outcome: 9.2/10
- Credible likelihood: 7.2/10
- Speed to useful value: 8/10
- Low buyer effort: 8.5/10
- Overall directional value strength: 8.2/10

### Biggest value leaks
1. The buyer must immediately understand why Accelerator is worth £300 more than Sprint.
2. Mixed-channel complexity can increase fulfilment risk if the extra scope is not sharply defined.
3. It should not exist merely as an anchor price.

### Upgrade
- Define the specific additional job or channels that create the premium.
- Use a small menu close only when both Sprint and Accelerator are genuinely suitable.
- Recommend one route rather than forcing the prospect to self-diagnose from a catalogue.
- Track gross margin and delivery complexity separately from Sprint.

### Stronger buyer-facing frame
**For businesses where one return channel is not enough, Accelerator expands the agreed system across the additional customer-contact points needed to close more of the journey gap without leaving the owner to coordinate separate tools and suppliers.**

## Optimisation - £595/month
### Value requirement
Recurring fees must buy recurring work and recurring commercial learning. The monthly job should remain concrete: monitoring, testing, journey improvements, lifecycle opportunities, reporting and prioritised optimisation within scope.

## Growth Partner - £1,495/month
### Value requirement
This must be a clearly higher-touch operating partnership, not 'Optimisation plus more access'. Define the additional decision support, operating depth, experimentation, expansion or ownership that justifies the step-up.

## Overall offer conclusion
The offer ladder is structurally strong enough to keep. The immediate weakness is not a need for more SKUs. It is **perceived likelihood and proof**, plus sharper articulation of what each step uniquely accomplishes.

Priority order:
1. create tangible RRC value;
2. make Growth Check visibly implementation-ready;
3. make Sprint start conditions and turnkey scope unmistakable;
4. clarify the exact premium job of Accelerator;
5. create appointment-led proof;
6. then test rollover credit, menu close or feature downsell without changing prices blindly.
