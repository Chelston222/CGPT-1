# Retention School ICP Field Kit Production Skill

Status: production skill
Owner: 222Emails / Retention School
Primary use: turn one approved ICP Field Kit source into a high-quality 10-slide LinkedIn carousel and reusable owned resource package.

## Objective

Produce one ICP resource at a time to the same or higher standard than the Chauffeur Open Quote Recovery carousel, while keeping the system repeatable, versioned, red-teamable and safe for future reuse.

The output is not merely a social post. Each ICP build must create an owned resource asset that can support LinkedIn, future reposting, resource pages, email, lead magnets and sales enablement.

## Non-negotiable generation rules

1. Work on one ICP kit at a time.
2. Maximum image-generation batch size is 10.
3. A 10-slide carousel therefore uses one generation batch of at most 10 separate image outputs.
4. Every slide is a separate generated image.
5. Never create a collage, contact sheet, grid, montage, merged slide board or multi-slide image.
6. Never substitute SVG, vector artwork, HTML screenshots, manually rendered PNGs or chat-generated download graphics for real image generation.
7. Do not merge slide images after generation.
8. Preserve the exact approved slide order.
9. Do not fabricate proof, results, client claims, percentages, revenue figures or benchmarks.
10. Use UK English and no em dashes in client-facing copy.
11. Use genuine logo artwork only when available. Omit a logo rather than recreating it inaccurately.
12. GBP, not USD, where money is shown.

## Creative benchmark

Use the Chauffeur Open Quote Recovery carousel as the quality and system benchmark, not as a literal template.

Preserve the Retention School visual family:

- premium editorial business-education aesthetic
- warm bone / cream foundations
- deep navy hierarchy
- restrained orange accents
- large, deliberate typography
- strong whitespace
- clear one-idea-per-slide discipline
- sophisticated diagrams, operating-system motifs, trackers, timelines and workflow visuals
- human-readable mobile composition
- no decorative clutter
- no excessive orange underlining
- no motivational-billboard aesthetic

Each new ICP should still look native to its category. Salon imagery can reference premium chairs, booking diaries, mirrors, client cards and appointment flow. Aesthetics can reference consultation/admin flow without making clinical promises. Dental can reference administrative treatment-plan flow without suggesting clinical automation.

## Source lock

Before image generation, lock:

- kit number
- ICP
- resource title
- commercial problem
- intended outcome
- tracker / worksheet structure
- SOP or cadence
- message-bank role
- exclusions and compliance boundaries
- 10-slide story
- CTA

Do not begin visual production while the story is still materially changing.

## Ten-slide architecture

Default structure:

1. ICP-specific hook / commercial tension
2. Define the hidden leak
3. Explain why the current behaviour fails
4. Introduce the core tracker / board / diagnostic
5. Show the operating logic or segmentation
6. Show the practical cadence / workflow
7. Show what the free resource contains
8. Show what to measure or what better operation looks like
9. Resource CTA / download page
10. Retention School category / brand close

This is a default, not a rigid formula. Change the structure when a stronger story exists, but preserve one clear idea per slide.

## Image-generation prompt contract

Use the following internal brief for every 10-slide generation batch:

> Create a premium 10-slide Retention School LinkedIn carousel as 10 SEPARATE single-image outputs, one output per slide. Never create a collage, grid, contact sheet, montage, merged board, composite of multiple slides, SVG, vector mock-up or downloadable PNG substitute. Each image must be a complete standalone slide in a consistent visual system. Use a premium editorial business-education aesthetic with warm bone/cream backgrounds, deep navy typography and restrained orange accents. Typography must be large, confident and highly legible on mobile, with strong hierarchy and generous whitespace. Use realistic, category-relevant visual storytelling, refined UI-like trackers, flow diagrams, appointment cards, operating-system motifs and subtle dimensional detail where helpful. Avoid stock-photo cliché, excessive decoration, excessive orange underlines and motivational-poster styling. Maintain consistent margins, corner treatment, typographic scale, visual language and brand feel across all ten slides. Use the approved slide copy and order exactly in meaning; improve layout, not claims. Do not invent proof, statistics or financial outcomes. If genuine logo artwork is unavailable, leave logo space clean rather than recreating a fake mark. Output exactly one separate image for each of the ten approved slides.

## Red Team Ultra gate

Before generation, attack:

- Is the problem specific enough to the ICP?
- Is this materially useful, or merely a disguised sales pitch?
- Does the resource solve an operational problem the ICP can recognise immediately?
- Is any claim unsupported?
- Are any slides redundant?
- Does the CTA arrive too early?
- Could any healthcare-adjacent wording be interpreted as clinical advice?
- Is the carousel visually likely to become repetitive?
- Can a reader understand the concept without already knowing 222Emails?

Fix root causes before image generation.

## Sequential double verification

Pass 1: content verification

For slides 1 through 10 in order, verify:

- exact ICP
- intended idea
- factual / evidence safety
- copy accuracy
- no em dash
- no accidental currency error
- CTA correctness
- no clinical overreach

Pass 2: visual verification

For slides 1 through 10 in order, verify:

- separate single-slide image
- not a collage
- typography readable at mobile size
- no text clipping
- no duplicated / missing slide
- visual consistency
- restrained orange
- good whitespace
- correct slide sequence
- no fake logo
- no malformed human anatomy or misleading category imagery

If any slide fails, regenerate only the failed slide(s) while preserving the approved system.

## Ship gate

Do not call a kit complete until:

- all ten slide images pass both verification passes
- PDF export contains exactly ten pages in correct order
- source kit remains stored separately
- visual source / generated outputs are preserved
- final PDF is stored in the owned resource library
- SHA / byte / page integrity is captured for governed publishing
- master tracker is updated
- the kit remains reusable after its first LinkedIn post

## Reuse rule

Never delete a resource because it has been posted. Keep the source kit, final carousel, final PDF, caption and publication record so it can later support reposting, derivatives, resource pages, email nurture, lead magnets and sales conversations.
