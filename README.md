# 222Emails Codex Starter

Initial seed commit for the 222Emails operating system.

## Agent CLI tooling

This repo now includes a CLI-first agent tooling plan inspired by the Printing Press workflow. See `docs/AGENT_CLI_TOOLING.md` for the recommended setup and `config/agent-cli-tools.example.json` for the current tool manifest.

Run the local readiness check with:

```bash
node scripts/check-agent-cli-tooling.mjs
```
