# Retention School ICP Field Kit Production Skill

Status: production
Owner: Chelston / 222Emails / Retention School

## Objective

Turn one appointment-led ICP problem into an owned Retention School Field Kit that can be stored, reused, converted into a LinkedIn PDF carousel, and later republished without rebuilding the source from scratch.

The source resource is the permanent asset. Social visuals are derivatives.

## Required outputs per kit

1. ICP and narrow commercial problem.
2. Useful resource with tracker fields, SOP/cadence, message templates, exclusions and metrics.
3. Ten-slide LinkedIn carousel script.
4. LinkedIn caption and CTA.
5. Production metadata: kit number, revision, status, source path, visual status, posting status and reuse status.
6. Ten separate generated slide images when visual production is requested.

## Visual production contract

- Real image generation only.
- Never create a collage, contact sheet, grid or merged multi-panel output.
- One generated image equals one carousel slide.
- Maximum 10 generated images per image-generation call.
- Default carousel length is 10 slides unless the source genuinely requires fewer.
- Do not create a fake PNG download-link workflow, SVG/vector substitute or coded render when the request is for image generation.
- Use the approved Retention School visual language: warm cream/bone base, deep navy, restrained orange accents, editorial typography, strong hierarchy, generous whitespace, premium practical-business aesthetic.
- Preserve legibility on mobile. Avoid dense copy.
- Do not invent logos. Use genuine supplied logo artwork when available; otherwise omit the logo rather than recreating it inaccurately.
- Do not fabricate testimonials, client names, revenue claims, percentages, benchmarks, star ratings, case studies or before/after results.
- Photography, when used, must feel specific to the ICP rather than generic corporate stock imagery.
- No em dashes in copy.

## Carousel structure

The default 10-slide flow is:

1. ICP-specific hook and problem.
2. Why the leak happens.
3. What to identify or segment first.
4. The core tracker or operating board.
5. The operating cadence or workflow.
6. Message/template example or decision logic.
7. What the free Field Kit contains.
8. What to measure and how to use it.
9. Download CTA for the specific Field Kit.
10. Retention School closing/category page.

The structure may change when that produces a materially better resource, but each slide must add a new idea or next step.

## Production workflow

### Stage 1: Source lock

- Confirm ICP.
- Confirm one narrow problem.
- Confirm the kit is materially distinct from existing kits.
- Build or retrieve the owned source resource.
- Keep claims procedural unless verified evidence exists.

### Stage 2: Red-team pass 1 - commercial usefulness

Attack:
- Is this actually a painful ICP problem?
- Would the target business use the tracker/SOP/templates?
- Is it too generic?
- Does it naturally connect to Client Return Systems without turning into a pitch?
- Is the CTA worth downloading?

Fix every material weakness before visual production.

### Stage 3: Carousel script

- Reduce the resource to ten visually strong slides.
- One core thought per slide.
- Keep the hook ICP-native.
- Keep body copy short enough for mobile.
- Remove motivational filler.
- Remove unsupported claims.

### Stage 4: Red-team pass 2 - visual and truth safety

Reject any slide that:
- requires invented proof;
- contains fake testimonials or results;
- repeats another slide;
- uses excessive small text;
- depends on a collage;
- creates an inaccurate logo;
- uses generic imagery that could belong to any ICP;
- overuses orange decoration or underlines.

### Stage 5: Image generation

- Generate each slide as an independent portrait image.
- A batch can contain up to 10 independent images.
- Never ask the model for one image containing all ten slides.
- Maintain visual continuity across the set while allowing layout variation.

### Stage 6: Sequential verification

Verification pass A - slide-by-slide:
- correct slide number and sequence;
- no clipped text;
- no obvious spelling corruption;
- no invented proof;
- no duplicate slide concept;
- no collage/merge;
- visual hierarchy works at feed size.

Verification pass B - set-level:
- consistent Retention School visual language;
- narrative progression makes sense;
- the resource matches the source kit;
- CTA matches the actual resource;
- no slide silently changes the offer or audience;
- final set is suitable for later PDF assembly and governed LinkedIn intake.

If either pass fails, regenerate only the affected slide(s), not the whole set by default.

## Storage rule

Never treat the posted PDF or social image as the only copy of the work.

Keep:
- source Field Kit;
- carousel script;
- generated individual slide assets;
- final PDF export once assembled;
- caption;
- stable kit ID and revision;
- published/scheduled URL and performance metadata when available.

## Priority rule

Build the library before over-optimising one kit. Prefer a strong repeatable 90-95 quality system across multiple ICPs, then improve the highest-performing resources using real evidence.

## Ship gate

A kit is VISUAL READY only when:
- source resource exists;
- carousel script is locked;
- ten independent images exist, or the approved slide count exists;
- no image is a collage or merged multi-panel;
- no unsupported claim or fabricated proof exists;
- sequential visual QA passes;
- source remains stored for future reuse.
