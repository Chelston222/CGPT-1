TRAINING & ACADEMY · WEB EDITION

Client Return, Made Simple.

Use this with your enquiry, application and enrolment pipeline open. The objective is to stop commercially serious learner intent disappearing between steps that were never clearly owned.

Core rule: do not add automation to a process you cannot explain on one page. Define the trigger, eligible person, next action, owner, stop condition and measurement first.

01 · DIAGNOSE

The six places value most often disappears.

The leak is not “manual follow-up” by default. It is the moment where the next commercially useful step becomes fragile, unclear or unowned.

StageCommercial questionFailure mode
EnquiryDid interest reach a useful next step?Warm prospect goes quiet
ApplicationDid an application reach the required decision or action?Incomplete application stalls
Deposit / paymentDid intent become a confirmed place?Commercial commitment pauses
Pre-startDid an enrolled learner actually reach the intake?Non-start is noticed too late
ProgressionWas the next suitable course or pathway visible?Completed learner has no defined next step
AlumniWas an appropriate reason to return or refer created?Past learners become a forgotten database

03 · BUILD

Six systems. Fix one before you build six.

01

Enquiry-to-next-step

Moment: A prospect asks but does not progress.

System job: Define the next useful action based on the programme journey.

02

Application recovery

Moment: An application starts but stalls.

System job: Make the missing step clear and stop when status changes.

03

Deposit / enrolment

Moment: A suitable prospect intends to join but has not confirmed.

System job: Remove operational friction without manufacturing urgency.

04

Pre-start assurance

Moment: A confirmed learner has not completed the actions required to start.

System job: Create timely operational prompts and human escalation.

05

Progression

Moment: A learner completes one programme and may suit another.

System job: Offer a relevant next pathway where it genuinely fits.

06

Alumni return

Moment: A past learner may return, upskill or refer.

System job: Segment by actual history and relevance rather than blasting the full database.

Priority rule: pick the leak with the clearest commercial value, enough eligible volume, a workable next action and a result you can actually measure.

04 · MESSAGE

Re-open the decision. Do not manufacture pressure.

These are frameworks, not copy-and-paste spam. Replace brackets with genuine context and make the message fit the relationship, channel and permission state.

Warm enquiry

You asked about [course/programme] recently. If it is still something you are considering, I can help with the next step or answer any practical questions about the process.

Incomplete step

It looks like [application/deposit step] is still incomplete. If you still want to join [programme], here is the simplest next action: [route].

Alumni progression

You previously completed [programme] with us. If [next relevant outcome] is now useful, we can show you the options that fit your previous training.

05 · 14-DAY TEST

Run a controlled recovery process, not a database blast.

Days 1–3Clean, suppress, segment and define the single objective.
Days 4–6Build the message, booking/enrolment route and reply ownership.
Days 7–10Launch to the eligible cohort and follow up proportionately.
Days 11–14Reconcile replies, conversions, completed value and learning.

Success is not an open rate. Useful outcomes are qualified replies, appropriate next steps, bookings or enrolments where evidenced, completed value where measurable, objections and operational friction.

06 · MEASURE

Use a small dashboard tied to decisions.

Conversion

Define the cohort, event and time window. Compare like with like.

Recovered value

Track booked/committed value separately from completed or realised revenue.

Learning

Record objections, non-response, reply ownership and process failures, not just campaign metrics.

07 · GUARDRAILS

Useful systems stay inside the business’s real authority.

Suitability, admissions decisions, funding eligibility, accreditation rules and learner-support decisions stay with the provider. Follow-up should clarify genuine next steps, not create false scarcity or misleading employability/income claims. UK marketing permissions still apply.

08 · 30-DAY PLAN

Turn the diagnosis into an operating rhythm.

Week 1Define states, ownership, eligibility and baseline numbers.
Week 2Build the highest-priority next-step journey.
Week 3Run a controlled recovery or return test.
Week 4Reconcile outcomes, document learning and decide what becomes ongoing.
